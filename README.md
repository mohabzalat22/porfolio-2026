# Mohab Ali Gaber — Portfolio

Dark, animated, mobile-first portfolio. React + Vite only — no UI/animation libraries, no database.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

## Customize

Everything lives in `src/data.js`:

- Replace the `"#"` links (LinkedIn, GitHub, WhatsApp, project repos).
- Edit projects, skills, experience, and Replytia copy.

Colors/spacing are CSS variables at the top of `src/styles.css`.

## Deploy

Upload `dist/` to Netlify, Vercel, Cloudflare Pages, or GitHub Pages.
